Frequently Asked Questions

How does the live top bar display work on Ubuntu? ▼

Timer utilizes the native StatusNotifierItem / Ayatana AppIndicator protocol directly in GNOME Shell. It dynamically updates the panel label without requiring any external extensions or session restarts.

Does Timer keep counting if my laptop goes to sleep? ▼

Yes. Timer uses monotonic clock timestamps instead of counting simple ticks. When the computer resumes, it calculates exact elapsed real-world time without drift.

Can I control the timer via terminal or keyboard scripts? ▼

Yes! You can run timer 25m, add time with timer +5m, or toggle pause/resume with timer --toggle.
